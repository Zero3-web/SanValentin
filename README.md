# 💖 San Valentín - Sorpresa Especial

Este es un proyecto web creado para celebrar el día de San Valentín. Permite crear una experiencia personalizada con mensajes, fotos y música para esa persona especial.

## 🚀 Características
- **Personalización**: Ajusta detalles como nombres, historias y fotos a través de `config.js`.
- **Multimedia**: Soporte para imágenes personalizadas y música de fondo.
- **Interactividad**: Diseño dinámico y animaciones románticas realizados con CSS y JavaScript vainilla.

## 🛠️ Tecnologías
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## 📦 Instalación y Uso
1. Clona este repositorio o descarga los archivos.
2. Abre `index.html` en cualquier navegador web moderno.
3. Para personalizar el contenido, edita el archivo `config.js`.

# 💖 Valentine's - Special Surprise

This is a web project created to celebrate Valentine's Day. It allows creating a personalized experience with messages, photos, and music for that special someone.

## 🚀 Features
- **Customization**: Adjust details like names, stories, and photos via `config.js`.
- **Multimedia**: Support for custom images and background music.
- **Interactivity**: Dynamic design and romantic animations built with CSS and vanilla JavaScript.

## 🛠️ Technologies
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## 📦 Installation and Usage
1. Clone this repository or download the files.
2. Open `index.html` in any modern web browser.
3. To customize the content, edit the `config.js` file.
